# MPP Viewer 2.5.1 — App Store "What's New"

## Suggested App Store Connect text

Command palette, color-coded phases, better printing, and modern Excel export.

NEW
• Command palette: press ⌘K to jump to any view or task by name, WBS, or ID
• Color your Gantt bars and whole phases — right-click a bar (or use the inspector) to set a color, shown across Gantt and Timeline
• Reorder phases by dragging them in the Gantt; a phase carries its whole subtree
• Focus mode and an outline-level filter to zoom into one phase or one altitude
• Multi-select tasks (⌘-click) to move, recolor, or mark complete in one step
• Trackpad haptic feedback when Gantt bars snap to a day or row

IMPROVED
• Excel exports and templates are now real .xlsx files that open cleanly (and can be re-imported)
• Printing works again and no longer prints blank pages
• Task names wrap fully in PDF exports and show on hover in the task list
• Task detail pane no longer overflows the window; toolbar stays visible

FIXED
• CSV import handles Excel/Windows files (CRLF) that previously imported nothing
• Gantt month labels no longer overlap at the start of the timeline
• Toolbar buttons show their tooltips on hover
