# MPP Viewer 2.3.0 — App Store "What's New"

## Suggested App Store Connect text

Export to Microsoft Project, undo/redo, and a faster, cleaner app.

NEW
• Export native plans to MS Project XML (MSPDI) — share your work with Microsoft Project and other PM tools
• Undo/redo in Plan Builder and Gantt editing (Cmd+Z / Cmd+Shift+Z)
• Click a task in the Schedule list to highlight its bar in the chart (and vice versa)
• Gantt, Schedule, and Timeline show extra runway after the last activity so final labels stay readable

IMPROVED
• Much faster Portfolio and Dashboard pages — heavy analysis now runs in the background
• Layout adapts to small windows: toolbars and chips reflow instead of truncating
• Full support for the macOS Tahoe floating sidebar — content stays in view on every page
• Hover feedback on all toolbar buttons and toggles
• Save problems are now reported instead of failing silently

FIXED
• Resource workload no longer under-counts the last working day of tasks
• Critical path now includes every task on the chain, not just the final ones
• Plan files carry a format version so newer files fail with a clear message instead of opening incorrectly
