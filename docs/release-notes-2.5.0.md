# MPP Viewer 2.5.0 — App Store "What's New"

## Suggested App Store Connect text

Custom task attributes, editable grid columns, and a faster app.

NEW
• Custom task fields: define your own attributes like Domain or Workstream — added to every task in the plan at once
• Custom fields show as columns in the Tasks view, are searchable, and can be edited directly in the Plan Builder grid
• Plan Builder grid column picker: hide built-in columns you don't need, and add Notes, Priority, and Fixed Cost as inline-editable columns

IMPROVED
• Smoother, faster Tasks view: cached review-note lookups, debounced search, and faster resource grouping on large plans
• Milestones page no longer re-sorts the list several times per refresh
• Removing a custom field asks for confirmation and is fully undoable

Includes the 2.4.x features: multi-select Gantt bar moves, more task list columns with drag-to-reorder, the new calendar date control, and CSV import fixes for Excel/Windows files.
