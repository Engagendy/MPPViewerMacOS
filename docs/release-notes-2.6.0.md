# MPP Viewer 2.6.0 — App Store "What's New"

## Suggested App Store Connect text

Presentation mode, SVG export, bulk resource assignment, and a faster, sharper Gantt.

NEW
• Presentation Mode (⇧⌘F): fullscreen, distraction-free executive view
• Export the Gantt chart as a scalable SVG for decks and design tools
• Bulk resource assignment: multi-select tasks and assign or unassign a resource in one step
• Double-click any split divider to reset the pane to its default size
• Quick Look groundwork for previewing .mppplan files in Finder

IMPROVED
• Command palette (⌘K) search now filters instantly as you type
• Gantt and Schedule open at the correct time position immediately — no more bars far from their dates until zooming
• Gantt and Schedule load noticeably faster on large plans
• Month labels adapt to the available space (Jan 2028 → Jan '28 → Jan)
• Under-the-hood modularization for faster builds and future features

Includes everything from 2.5.x: custom task fields, editable grid columns, bar and phase colors, phase drag-reorder, focus and level filters, .xlsx exports, and print fixes.
