# MPP Viewer 2.4.1 — App Store "What's New"

## Suggested App Store Connect text

Move several Gantt bars at once.

NEW
• Multi-select in Gantt edit mode: Command-click bars or rows to select several tasks
• Nudge the whole selection with the arrow keys — one day per press, a week with Shift
• Drag any selected bar to move the entire selection together
• A group move is a single undo step — Cmd+Z reverts all of it at once

Includes everything from 2.4.0: more task list columns with drag-to-reorder, the new calendar date control, CSV import fixes for Excel/Windows files, and smoother Gantt editing.
