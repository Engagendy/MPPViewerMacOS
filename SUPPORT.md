# Planroom Support

Planroom support is available by email and through GitHub.

## Contact

- Email: engagendy@gmail.com
- GitHub issues: https://github.com/Engagendy/MPPViewerMacOS/issues

For bug reports, include your macOS version, Planroom version, the type of file you opened (`.mpp` or `.mppplan`), and the steps that reproduce the issue.

## Sample Files

Use the included showcase plan to review the app's native planning, portfolio, Gantt, resource, calendar, status, earned value, and workload features:

- Sample plan page: https://github.com/Engagendy/MPPViewerMacOS/blob/main/docs/sample-plans/aurora-commerce-launch.mppplan
- Direct download: https://raw.githubusercontent.com/Engagendy/MPPViewerMacOS/main/docs/sample-plans/aurora-commerce-launch.mppplan

## App Review Notes

Open the sample `.mppplan` file, then start in `Portfolio`, `Dashboard`, `Plan Builder`, `Gantt Chart`, `Resources`, `Calendar`, `Status Center`, `Earned Value`, and `Workload` to exercise the main workflows.
